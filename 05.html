分析题模板

五、分析题模板与万能金句

史纲分析题固定在第 36 题，10 分。阅卷是按点给分，答案必须"分点、带术语、有史实、落到结论"。

一、史纲分析题只有三种问法

问法 典型设问 答题重心
为什么类 "为什么说……是历史的必然？" 原因（客观＋主观）＋史实＋结论
意义类 "如何理解……的伟大意义？" 定性＋分条意义（历史／现实／理论）
启示类 "……对我们今天有什么启示？" 历史结论＋现实映射（新时代）

通用公式：定性判断（是什么）→ 史实支撑（2～3 个）→ 分析论证（为什么）→ 结论升华（四个选择／复兴）。

二、答题结构（四步法，考场直接套）

第一段（1～2 句）：定性。
    "××是近代中国历史发展的必然结果，是……的标志/转折/开端。"

第二段（3～4 点）：史实 + 分析。
    每点格式："史实（时间＋事件）→ 这说明……"
    不要只罗列事件，每一条后面必须跟一句"说明/表明/证明"。

第三段（2～3 句）：意义/结论。
    落到"四个选择""中华民族伟大复兴""历史和人民的选择"。

第四段（1 句，可选）：现实启示。
    "今天……仍然/更加需要……"

三个硬要求 1. 必须分点（①②③），一段到底最多拿一半分； 2. 必须有史实，只讲道理不给史实，评分点会空； 3. 必须落到结论，不落到"四个选择/复兴"的答案，最后一档分数拿不到。

三、六大母题的答题骨架

母题 1　中国共产党的成立（"开天辟地的大事变"）

为什么是"开天辟地的大事变"？ 1. 近代以来，农民阶级、地主阶级洋务派、资产阶级维新派和革命派先后探索，都未能改变半殖民地半封建的社会性质——历史需要一个新力量。 2. 十月革命送来马克思列宁主义，五四运动使工人阶级登上政治舞台，马克思主义与中国工人运动相结合——党具备了阶级基础和思想基础。 3. 中国共产党成立后，中国革命有了坚强的领导核心、科学的指导思想、明确的奋斗目标和新的革命方法，中国革命的面貌焕然一新。 4. 结论：中国共产党的成立，是开天辟地的大事变，深刻改变了近代以后中华民族发展的方向和进程，深刻改变了中国人民和中华民族的前途和命运。

母题 2　中国革命新道路（农村包围城市、武装夺取政权）

  1. 背景：大革命失败，城市暴动接连受挫，照搬俄国道路行不通。
  2. 探索：八七会议定方针 → 南昌起义、秋收起义 → 井冈山根据地 → 《星星之火，可以燎原》。
  3. 内容："工农武装割据"——土地革命、武装斗争、根据地建设三者结合。
  4. 依据：中国是半殖民地半封建大国，政治经济发展不平衡，农民占绝大多数，敌人力量集中于城市。
  5. 意义：是马克思主义基本原理同中国革命具体实际相结合的典范，标志着马克思主义中国化的开端。

母题 3　抗日战争（中流砥柱）

  1. 民族矛盾上升：九一八后日本侵华，七七事变后全民族抗战。
  2. 中国共产党提出并坚持全面抗战路线，制定《抗日救国十大纲领》。
  3. 提出持久战战略，科学预见三个阶段，坚定抗战信心。
  4. 开辟敌后战场，成为坚持抗战的中坚力量。
  5. 维护抗日民族统一战线，坚持独立自主原则。
  6. 结论：中国共产党是抗日战争的中流砥柱；抗战胜利是近代以来第一次完全胜利的民族解放战争，重新确立了中国的大国地位。

母题 4　新中国的成立与社会主义制度的确立

  1. 新中国成立（1949）：新民主主义革命基本胜利，中国人民站起来，为实现由新民主主义向社会主义过渡创造了前提。
  2. 过渡时期总路线（1953）："一化三改"，主体是社会主义工业化。
  3. 三大改造（1956 年基本完成）：农业、手工业走合作化，资本主义工商业实行和平赎买——这是中国共产党的创举。
  4. 意义：社会主义基本制度确立，中国进入社会主义初级阶段，这是中国历史上最深刻最伟大的社会变革，为当代中国一切发展进步奠定了根本政治前提和制度基础。

母题 5　改革开放

  1. 背景："文化大革命"结束后，中国面临向何处去的历史抉择。
  2. 转折：十一届三中全会重新确立解放思想、实事求是的思想路线，把工作重心转移到经济建设上来，作出改革开放的历史性决策。
  3. 进程：农村改革 → 城市改革 → 社会主义市场经济体制（十四大）→ 加入世贸组织 → 全面深化改革。
  4. 意义：改革开放是决定当代中国命运的关键一招，是党和人民事业大踏步赶上时代的重要法宝；它不是否定社会主义制度，而是社会主义制度的自我完善和发展。

母题 6　新时代与中国式现代化

  1. 方位：十八大以来，中国特色社会主义进入新时代，社会主要矛盾转化为人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾。
  2. 使命：实现中华民族伟大复兴的中国梦。
  3. 成就：新时代十年的伟大变革，在"五史"上具有里程碑意义。
  4. 中国式现代化：人口规模巨大、全体人民共同富裕、物质文明和精神文明相协调、人与自然和谐共生、走和平发展道路的现代化。
  5. 结论：中国式现代化打破了"现代化＝西方化"的迷思，为人类实现现代化提供了新的选择。

四、万能金句（按主题备一小本）

关于"历史必然性"

  • 这是近代中国历史发展的必然结果，是历史和人民的选择。
  • 事实证明，照搬别国道路行不通，只有把马克思主义基本原理同中国具体实际相结合才能成功。
  • 一种方案行不行，不看它多"先进"，而看它能不能解决中国的实际问题。

关于"意义"

  • 深刻改变了近代以后中华民族发展的方向和进程，深刻改变了中国人民和中华民族的前途和命运。
  • 为实现中华民族伟大复兴提供了根本政治前提、制度基础、物质条件和精神力量。
  • 在党史、新中国史、改革开放史、社会主义发展史、中华民族发展史上具有里程碑意义。

关于"启示"

  • 必须坚持中国共产党的领导，必须坚持马克思主义的指导地位，必须坚持走自己的路。
  • 必须坚持以人民为中心，必须坚持独立自主、自力更生。
  • 空谈误国，实干兴邦；幸福都是奋斗出来的。

关于"四个选择"（收口句）

近代以来的历史反复证明：历史和人民选择马克思主义、选择中国共产党、选择社会主义道路、选择改革开放是完全正确的，必须坚定不移走下去。

五、常见失分点

失分表现 后果 纠正
只罗列史实，不写"说明/表明" 只得史实分，丢分析分 每条史实后强制加一句结论
不分点、写成一大段 阅卷找不到点 一定用①②③
用口语，不用学科术语 显得不专业 背"标志""转折""确立""必然"等词
只写意义，不写原因 答非所问 先看设问是"为什么"还是"意义"
结尾不收口 丢最后一档分 固定加"四个选择/复兴"一句
时间写错 硬伤 只写"×世纪×年代"也比写错年份安全

六、示范：一道完整答案

设问：结合史实，说明为什么说中国共产党的成立是"开天辟地的大事变"。（10 分）

参考答案

① 中国共产党的成立，是近代中国历史发展的必然结果。（定性）

② 鸦片战争后，中国逐步沦为半殖民地半封建社会。农民阶级的太平天国运动、地主阶级洋务派的洋务运动、资产阶级维新派的戊戌变法和资产阶级革命派的辛亥革命，先后进行了探索，但都没有改变中国半殖民地半封建的社会性质，也没有完成反帝反封建的任务。这说明，旧式的阶级力量和旧式的革命道路已经不能解决中国的问题，历史呼唤新的领导力量。（史实＋分析）

③ 十月革命一声炮响，给中国送来了马克思列宁主义；五四运动中，中国工人阶级以独立的姿态登上政治舞台，马克思主义在中国广泛传播并同中国工人运动相结合。中国共产党正是在这样的阶级基础和思想基础上诞生的。（条件）

④ 中国共产党成立后，中国革命有了坚强的领导核心、科学的指导思想、明确的奋斗目标和新的革命方法，中国革命的面貌焕然一新。从此，中国人民谋幸福、中华民族谋复兴有了主心骨，中国革命有了正确的前进方向。（意义）

⑤ 由此可见，中国共产党的成立是开天辟地的大事变，深刻改变了近代以后中华民族发展的方向和进程，深刻改变了中国人民和中华民族的前途和命运。历史和人民选择中国共产党是完全正确的。（收口）

评分点拆解：定性 1 分 + 四次探索失败 3 分 + 阶级基础与思想基础 2 分 + "焕然一新"四个新 2 分 + 结论收口 2 分。
